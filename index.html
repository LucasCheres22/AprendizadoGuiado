Biblioteca de Receitas de Código
Onda de Oceano (Seno)
Cria uma onda dinâmica oscilando no tempo baseada em coordenadas.
const onda = Math.sin(x * 0.4 + time) * 0.8;
Colinas Suaves (Perlin)
Ruído Perlin 2D contínuo e natural de altitude média.
const colina = noise2d(x * 0.15, z * 0.15) * 1.8;
Montanhas Acidentadas (fBm)
Somatório fractal de oitavas de ruído para picos de grande altitude.
const montanha = fbm2d(x * 0.22, z * 0.22, 4) * 3.5;
Micro Pedregulhos (Ruído Fino)
Ruído de alta frequência e baixa amplitude para simular solo rugoso.
const detalhe = noise2d(x * 1.8, z * 1.8) * 0.15;
Máscara Radial de Ilha
Decaimento radial em direção às bordas, ideal para isolar terrenos.
const mascara = Math.max(0, 1.0 - Math.sqrt(x*x + z*z) / 6.0);
Fórmulas de Retorno (Combinações)
Somar Relevos (Acumular)
Soma as duas variáveis para acumular as elevações (ex: ondas em cima de colinas).
return onda + colina;
Multiplicar por Máscara (Isolar)
Multiplica o relevo por uma máscara para manter as bordas niveladas na água.
return montanha * mascara;
Junção de Picos (Máximo)
Compara as duas alturas e mantém a maior delas em cada vértice.
return Math.max(onda, colina);
Média Suave
Tira a média aritmética simples das duas elevações.
return (onda + colina) / 2.0;
